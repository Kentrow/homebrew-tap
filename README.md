# Homebrew tap of Tapyr

[Tapyr](https://tapyr.eu) is a declarative API-to-metrics gateway that plans and spends API quota deliberately.

```sh
brew install kentrow/tap/tapyr
brew trust kentrow/tap            # once, so that a plain `brew upgrade` includes it
```

The files of `Casks/` are generated by the release workflow of [Kentrow/tapyr](https://github.com/Kentrow/tapyr): do not edit them here. Issues and pull requests belong in that repository.

The macOS binary is not notarized by Apple: the cask removes its quarantine attribute at install. The [install guide](https://docs.tapyr.eu/latest/install/) shows how to verify the signatures of a release.
